# Add repository-scoped issue creation and lookup

## What to build

Add the first end-to-end `orca issue` workflow for a single repository: create an issue, persist it in Orca's SQLite store under `~/.orca`, assign it a repo-scoped zero-padded ID, and retrieve it with `show`. Repository scope should resolve from the current git repo by default, support `--repo <path>`, and fail clearly when no repository can be resolved.

## Acceptance criteria

- [ ] `orca issue create --title ...` lazily initializes the SQLite store, creates an issue in the resolved repository scope, defaults status to `todo`, allows an empty body, and prints only the new zero-padded issue ID.
- [ ] `orca issue show <id>` returns the created issue for the resolved repository, including its metadata and raw body, and fails with a clear non-zero error when the issue does not exist.
- [ ] Repository resolution, repo-scoped ID allocation, padded ID rendering, and creation/show behavior are covered by integration-style tests using temporary repos and temporary Orca state.

## Blocked by

None - can start immediately
