# Add issue dependency graph management

## What to build

Add structured blocker management for repository-scoped issues. The issue CLI should support adding and removing dependency edges, enforce same-repo dependencies only, reject missing blockers, reject self-dependencies and cycles, expose reverse dependencies in `show`, and support direct blocker filtering in `list`.

## Acceptance criteria

- [ ] `orca issue block <id> <blocker...>` and `orca issue unblock <id> <blocker...>` mutate dependency edges atomically for a single target issue and remain silent on success.
- [ ] Dependency operations reject missing IDs, cross-repo references, self-dependencies, and cycles with clear non-zero errors, and `orca issue list --blocked-by <id>` returns direct downstream issues or errors if the referenced issue does not exist.
- [ ] `orca issue show` and `orca issue show --json` expose direct blockers and reverse dependencies, and the dependency graph behavior is covered by integration-style tests.
