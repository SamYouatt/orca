# Add issue listing with text and JSON views

## What to build

Add `orca issue list` as the read-side view over repository-scoped issues. The command should render a compact text view by default, support JSON output for agents, include completed issues in the default view, sort by repo-scoped issue ID, and allow repeated status filters.

## Acceptance criteria

- [ ] `orca issue list` shows all issues for the resolved repository in ascending issue ID order, including `done` issues, with compact text output that includes ID, status, title, and blocker IDs.
- [ ] `orca issue list --json` returns structured issue data suitable for machine consumption, while `show --json` remains self-describing for downstream tooling.
- [ ] Repeated `--status` filtering and the read-output contracts are covered by integration-style tests without relying on implementation details.
