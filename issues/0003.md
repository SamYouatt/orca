# Add patch updates for issue fields and blocker sets

## What to build

Add `orca issue update` as the patch-style mutation command for issue fields and blocker sets. The command should allow targeted updates to title, status, and body, support either full blocker replacement or incremental blocker edits, and reject ambiguous, empty, and no-op mutations.

## Acceptance criteria

- [ ] `orca issue update <id>` applies patch-style changes to title, status, and body while leaving omitted fields unchanged, including support for explicitly clearing the body.
- [ ] Blocker update modes support either `--blockers` replacement or `--add-blockers` / `--remove-blockers` patching, reject mixed modes in one call, and preserve the atomic dependency-validation rules.
- [ ] Empty updates and no-op blocker mutations fail clearly, while successful updates remain silent and are covered by integration-style tests.
